# claude-code-read-aloud

Claude の最新の回答を macOS の `say` で読み上げる、Claude Code の mod（function hooks のプラグイン）。読んでいる単語をパネル上で反転表示する。

## インストール

macOS 専用。`say` と `/usr/bin/perl` を使い、どちらも macOS に最初から入っている。

ターミナルで動かしている Claude Code のプロンプトで、次の1行を実行する。`Add marketplace?` には `y` で答える。続くスコープの選択では、すべてのプロジェクトで使うなら一覧の先頭の user を選ぶ。

```
/plugin install read-aloud --marketplace kesuuyof/claude-code-read-aloud
```

シェルからは次のとおり。

```bash
claude plugin marketplace add kesuuyof/claude-code-read-aloud
claude plugin install read-aloud@claude-code-read-aloud
```

デスクトップアプリでは `/plugin` が使えない。プロンプト欄の横の + から Plugins を開き、Add marketplace に `kesuuyof/claude-code-read-aloud` を入れてから、Add plugin で read-aloud を追加する。

user スコープで入れると、それ以降に始めたセッションで読み込まれる。デスクトップアプリの Code タブのセッションも含む。

日本語の声が1つ以上必要。拡張（Enhanced）かプレミアム（Premium）の日本語の声があればそれを使い、なければ Kyoko か Otoya を、それもなければほかの日本語の声を使う。声は、システム設定で「システムの声」を検索し、その項目から追加できる。声は最初に ▶ を押したときに選び、Claude Code を終了するまで（`/clear` のあとも）変えない。あとから声を追加したときは、Claude Code を起動し直すと使われる。

## 使い方

セッションを始めると「読み上げ」パネルが開く。閉じたあとは `/read-aloud` で開き直せる。回答が届いても自動では読まず、ボタンを押したときだけ読む。

- **▶ 再生**：最新の回答を先頭から読む。読んでいる単語を反転表示し、その単語を含む文に色を付ける。
- **⏸ 一時停止**：その位置で止める。ボタンが「▶ 続きから」に変わり、押すとそこから読む。
- **■ 停止**：止めて先頭に戻る。
- **− と +**：速度を 0.8x から 3x のあいだで変える。読んでいる途中で変えると、その位置から新しい速度で読み直す。選んだ速度は次のセッションにも引き継ぐ。
- **▸**（各文の行頭）：その文から読む。

パネルには回答を1文1行で表示する。表示と読み上げでは Markdown の記号を外し、コードブロックを「（コード省略）」に、URL を「URL」に置き換える。表は行ごとに、セルを「、」でつないだ1行にする。

読み上げ中に新しい回答が届いたときは、読み終えるか ■ で止めるまで、今の回答を表示したままにする。一時停止しているあいだ（パネルを閉じたあとも含む）に新しい回答が届くと、表示はその回答に切り替わり、止めた位置は失われる。サブエージェントの回答は対象にしない。

## 既知の制限

- **音声出力の切り替え**：AirPods から内蔵スピーカーに切り替わるなど、音声の出力先が変わると `say` は途中で終了する。最後の文より前で終わったときは位置を残して止まるので、▶ で続きから読める。最後の文の途中で終わったときは、読み終えた扱いになって先頭に戻る。
- **「/」の手前で反転表示が止まる**：`say` は、「/」の前にある最も近い空白から「/」までを1語として扱う。日本語の文には空白が少ないのでこの1語が長くなり、読み終えるまで反転表示が進まない。1x では、この1語の6字ごとに約1秒止まる。
- **速度の倍率**：倍率ごとの `say -r` の値は、Kyoko で測った表で決めている。ほかの声では、倍率と実際の速さがずれることがある。

## 開発

```bash
claude plugin validate .
claude plugin test .
claude --plugin-dir .
```

型定義（`.claude-plugin/types/`）は、Claude Code が mod を読み込むたびに生成する。一度読み込んだあとなら、`tsc -p .` で型チェックできる。

Claude Code 2.1.309 では、子プロセスの細かい出力を受け取り続けると、途中から出力も終了も届かなくなることがある。これを避けるため、`say` の出力は perl に通し、新しい出力が 80 ms 途切れるたびに、それまでの分をまとめて受け取る。それでも出力が途切れたまま、1x で 45 秒（速度を上げるほど短くなる）たつと、位置を残して一時停止する。Claude Code 側でこの不具合が直ったら perl を外す（`hooks/register.tsx` の `ponytail:` の箇所）。
